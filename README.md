# sunyucheng-writing-skill

一个文笔 skill。

2026年8月27日，孙宇晨在推特发了一篇文章，《我的女友景甜》。全文六千九百字，三百一十二个自然段，没有一个感叹号。

## 里面有什么

`sunyucheng-writing-skill/SKILL.md`。七条律则：

1. 零度情感。越痛越平。
2. 数字即抒情。一颗卵子，三点五微克。
3. 短句白描。最重的问题用句号。
4. 回环重复。同一句话，每次更重。
5. 物件载情。情绪只住在东西上。
6. 旁观者之眼。她知道那两个女孩叫什么。
7. 冷幽默实录。荒诞不使眼色。

另有十条启发式，五个陷阱，一份逐字分析，一份全文语料。语料是用来校准手感的。

## 现在有两个 skill

`sunyucheng-writing-skill`：文笔。一篇文章里拆出来的，七条律则。

`sunyuchen-perspective`：人格。一百七十个来源里拆出来的，七个心智模型。

一个管他怎么写。一个管他怎么赢。

## 怎么用

把整个目录放进你的 skills 文件夹。然后说，用 sunyucheng-writing-skill 写。

它会写得很短。写得很平。写到最后，什么都没有发生。

## 示例

让它写「加班到凌晨」：

> 项目上线那晚，办公室剩四个人。
>
> 外卖是十一点到的，三十五块的煲仔饭，锅巴很硬。
>
> 两点四十，服务器没崩。小王第一个走的，他女儿第二天幼儿园面试。
>
> 我站在窗边看了一会儿。对面写字楼还有三层亮着。
>
> 我数了一下，十一扇窗。
>
> 我关了灯。

## 它做不到什么

它不能替你伤心。它只能把伤心写成一个数字，或者一个物件。

它只代表那一篇文章，不代表孙宇晨。
